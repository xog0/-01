# صندوق الرَّكيزة — موقع صندوق استثماري مُدار

موقع ثنائي اللغة (عربي RTL + إنجليزي LTR) لصندوق استثماري يوزّع رأس المال على
**العقار** و**الأسهم والصناديق** و**المشاريع والشركات الناشئة**، مع لوحة إدارة
داخلية ونموذج طلب استثمار.

> **إشعار:** كل الأسماء والأرقام والنصوص الحالية **بيانات تجريبية**. غيّرها قبل
> النشر الحقيقي، وراجع المحتوى قانونياً — عرض أرقام أداء أو دعوة للاكتتاب قد
> يخضع لتنظيم الجهة المالية في بلدك.

---

## التشغيل محلياً

```bash
npm install
npm run dev          # http://localhost:3000 → يحوّل تلقائياً إلى /ar
```

الموقع يعمل كاملاً **بدون قاعدة بيانات**؛ يعرض بيانات تجريبية من
`src/lib/data/seed.ts` حتى تربط Supabase.

## البناء والفحص

```bash
npm run build        # بناء الإنتاج
npm run lint         # فحص ESLint
npm start            # تشغيل نسخة الإنتاج
```

## ربط Supabase (لوحة الإدارة وحفظ الطلبات)

1. أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com).
2. افتح **SQL Editor ← New query**، والصق محتوى `supabase/schema.sql` كاملاً ثم **Run**.
   الملف ينشئ الجداول وسياسات الحماية (RLS) وبيانات بدء للأداء.
3. من **Project Settings ← API** انسخ `Project URL` و `anon public key`.
4. أنشئ ملف `.env.local` في جذر المشروع:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
   NEXT_PUBLIC_SITE_URL=https://your-domain.com
   ```

5. أنشئ حساب المدير من **Authentication ← Users ← Add user** (بريد + كلمة مرور).
6. أعد التشغيل، ثم ادخل على `/ar/admin` — سيطلب تسجيل الدخول.

بمجرد امتلاء الجداول يقرأ الموقع منها تلقائياً بدل البيانات التجريبية، صفحةً صفحة.

## النشر على Vercel

1. ارفع المستودع إلى GitHub.
2. في [vercel.com](https://vercel.com) اختر **Add New ← Project** واستورد المستودع.
3. أضف نفس متغيّرات `.env.local` في **Settings ← Environment Variables**.
4. اضغط **Deploy** — لا يحتاج المشروع أي إعدادات بناء إضافية.

## تخصيص الهوية

| ما تريد تغييره | أين |
|---|---|
| اسم الصندوق، العملة، الهاتف، البريد، رقم واتساب، الحد الأدنى | `src/lib/site.config.ts` |
| نصوص الموقع بالعربية | `src/lib/i18n/dictionaries/ar.ts` |
| نصوص الموقع بالإنجليزية | `src/lib/i18n/dictionaries/en.ts` |
| الألوان (كحلي/ذهبي) والخطوط | `src/app/globals.css` (كتلة `@theme`) |
| شعار SVG | `src/components/site/Logo.tsx` |
| البيانات التجريبية | `src/lib/data/seed.ts` |

**رقم واتساب:** ضعه في `siteConfig.contact.whatsapp` بصيغة دولية بدون `+`
وبدون مسافات، مثل `966550000000`.

## بنية المشروع

```
src/
├─ app/
│  ├─ [locale]/
│  │  ├─ layout.tsx            ← الجذر: يضبط lang و dir حسب اللغة
│  │  ├─ (site)/               ← الموقع العام (هيدر + فوتر + زر واتساب)
│  │  │  ├─ page.tsx              الرئيسية
│  │  │  ├─ about | strategy | performance | faq | contact
│  │  │  ├─ opportunities/[slug]  الفرص + صفحة تفاصيل + حاسبة عائد
│  │  │  └─ insights/[slug]       المدونة والتقارير
│  │  └─ admin/
│  │     ├─ login/             ← تسجيل دخول Supabase
│  │     └─ (dashboard)/       ← نظرة عامة، الطلبات، الفرص، الأداء، المنشورات
│  ├─ api/requests/route.ts    ← استقبال نموذج طلب الاستثمار
│  └─ robots.ts
├─ components/  (site · charts · ui · forms · admin)
├─ lib/
│  ├─ i18n/          القواميس وإعداد اللغتين
│  ├─ data/          طبقة القراءة: Supabase أولاً ثم البيانات التجريبية
│  ├─ supabase/      عملاء الخادم والمتصفّح
│  ├─ charts.ts      لوحة ألوان الرسوم
│  └─ site.config.ts
└─ proxy.ts          توجيه اللغة + حماية /admin
```

### الرسوم البيانية

مرسومة بـ SVG مباشرة بلا مكتبات خارجية: مخطط مساحة لتطوّر صافي قيمة الأصول،
شريط مكدّس لتوزيع الأصول، وأعمدة للعائد السنوي تقبل القيم السالبة.
ألوانها مُختبرة لعمى الألوان (فصل ΔE كافٍ في protan/deutan/tritan) وتباين
٣:١ على الأقل مقابل الخلفية، ولكل مخطط جدول مكافئ مخفي لقارئات الشاشة.

### نموذج طلب الاستثمار

يُحفظ الطلب في جدول `investment_requests` ويظهر في لوحة الإدارة، **بالإضافة**
إلى زر واتساب للتواصل الفوري. بدون Supabase يُسجَّل الطلب في سجلّ الخادم
ويبقى زر واتساب هو القناة العملية.

## اللغتان والتوجيه

- `/ar` عربي RTL و `/en` إنجليزي LTR — نفس المسارات بنفس الـ slugs.
- الزائر الجديد يُحوَّل حسب `Accept-Language`، ويُحفظ اختياره في كوكي `locale`.
- الأرقام تُعرض بالأرقام اللاتينية في اللغتين (`ar-SA-u-nu-latn`) لأنها الأوضح
  في السياق المالي؛ غيّرها من `siteConfig.locale` إن أردت الأرقام العربية.

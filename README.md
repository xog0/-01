# موقع ٣ أسياخ — شاورما ومشاوي على الفحم

موقع تعريفي احترافي: واجهة، منيو تفاعلي، عن المطعم، معرض صور، آراء العملاء،
معلومات التواصل وأوقات الدوام، وزر طلب مباشر عبر واتساب.

## ⚠️ بيانات تحتاج تأكيد المالك

مكتوبة داخل `assets/js/config.js` وبجانبها علامة `(( ))`:

| البند | القيمة الحالية | الحالة |
| --- | --- | --- |
| رقم الجوال / الواتساب | `+966560651635` | من دليل عام — **يحتاج تأكيد** |
| العنوان | جدة — حي ميناء جدة الإسلامي | تقريبي — **يحتاج العنوان الدقيق** |
| رابط خرائط جوجل | بحث بالاسم | **يحتاج الرابط المباشر للفرع** |
| أوقات الدوام | ١٢ ظهراً – ٢ فجراً | افتراضية — **تحتاج تأكيد** |
| البريد الإلكتروني | فارغ | يختفي القسم تلقائياً حتى تضيفه |
| حسابات التواصل | فارغة | تختفي حتى تضيفها |

أسعار استُنتجت من نطاقات وردت في المنيو وتحتاج تأكيداً (في `assets/js/menu-data.js`):
وجبة عربي مكس ٣١ • أرز مكس ٣٠ • بوكس مكس ٨٨ • حمص ٨٫٥ • بطاطس ١٥٫٥.

**آراء العملاء:** المصفوفة فارغة عمداً — لا تُوضع تقييمات غير حقيقية. أضف تقييمات
حقيقية من خرائط جوجل في `window.TESTIMONIALS` فيظهر القسم تلقائياً.

- **الطراز:** عصري داكن وفخم (أسود + ذهبي).
- **اللغة:** عربي + إنجليزي مع زر تبديل (يغيّر اتجاه الصفحة تلقائياً RTL/LTR).
- **التقنية:** HTML + CSS + JavaScript بدون أي مكتبات خارجية — سريع جداً ويُستضاف مجاناً.
- **الجوال:** متجاوب بالكامل مع قائمة جانبية وشريط تصنيفات قابل للسحب.

## نسختان من نفس الموقع

| النسخة | الملف | متى تستخدمها |
| --- | --- | --- |
| **ملف واحد** | `3asyakh-single-file.html` | افتحه بأي متصفح، أو ارفعه لأي استضافة كما هو. كل شيء بداخله. |
| **مشروع مقسّم** | `index.html` + `assets/` | أسهل للتعديل والصيانة على المدى الطويل. |

النسخة ذات الملف الواحد **مُولَّدة** من المشروع المقسّم. بعد أي تعديل، أعد بناءها:

```bash
python3 build-single-file.py
```

## كيف أشغّل الموقع على جهازي؟

افتح ملف `index.html` (أو `3asyakh-single-file.html`) مباشرة في المتصفح.
أو شغّل خادماً محلياً:

```bash
npx http-server -p 8080
```

ثم افتح `http://localhost:8080`.

## أين أعدّل المحتوى؟ (بدون خبرة برمجية)

كل ما تحتاج تغييره موجود في ثلاثة ملفات فقط:

| ما تريد تغييره | الملف |
| --- | --- |
| اسم المطعم، الهاتف، الواتساب، العنوان، الدوام، السوشيال، تطبيقات التوصيل | `assets/js/config.js` |
| الأصناف والأسعار والأوصاف وآراء العملاء | `assets/js/menu-data.js` |
| نصوص الواجهة (العناوين والجمل التسويقية) بالعربي والإنجليزي | `assets/js/i18n.js` |
| الألوان والخطوط | أعلى ملف `assets/css/style.css` داخل `:root` |
| الصور | مجلد `assets/img/` — اقرأ `assets/img/README.txt` |

### مثال: تغيير رقم الواتساب
في `assets/js/config.js`:

```js
whatsapp: "966500000000",   // بصيغة دولية، بدون + وبدون مسافات
```

### مثال: إضافة صنف جديد
في `assets/js/menu-data.js` انسخ أي سطر صنف وعدّله:

```js
{ name: { ar: "سيخ شاورما جبنة", en: "Cheese Shawarma Skewer" },
  desc: { ar: "مع جبنة موزاريلا", en: "With mozzarella" },
  price: 14, badge: "new", img: null },
```

يقبل `price` رقماً (`14` أو `8.5`) أو نصاً لنطاق سعري (`"2 – 2.5"`).

قيم `badge` المتاحة: `"popular"` (الأكثر طلباً) أو `"spicy"` (حار) أو `"new"` (جديد) أو `null`.

### مثال: تغيير الألوان
في `assets/css/style.css`:

```css
--gold:#c9a227;        /* اللون الأساسي */
--gold-soft:#e6cd7d;   /* الدرجة الفاتحة */
--bg:#0c0a08;          /* خلفية الموقع */
```

## النشر على الإنترنت

**الأسرع (مجاناً):**
1. GitHub Pages: من إعدادات المستودع → Pages → اختر الفرع → Save.
2. أو اسحب مجلد المشروع إلى [netlify.com/drop](https://app.netlify.com/drop).

**لربط نطاق خاص** (مثل `restaurant.com`) أضف النطاق من إعدادات الاستضافة
ووجّه سجلات DNS حسب التعليمات التي تظهر لك هناك.

## بنية الملفات

```
3asyakh-single-file.html   نسخة الملف الواحد (مُولَّدة)
build-single-file.py       سكربت بناء نسخة الملف الواحد
index.html                 الصفحة الرئيسية (كل الأقسام)
assets/css/style.css       التنسيق والألوان والتجاوب
assets/js/config.js        معلومات المطعم  ← عدّل هنا
assets/js/menu-data.js     المنيو والآراء  ← عدّل هنا
assets/js/i18n.js          نصوص الواجهة بلغتين
assets/js/app.js           منطق الموقع (لا يحتاج تعديل)
assets/img/                الصور
```

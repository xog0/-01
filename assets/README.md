# صور الموقع

ضع الصور هنا بهذه الأسماء بالضبط، وستظهر تلقائياً في الصفحة.
وإن لم يوجد الملف، يظهر مكانه وصف الصورة بدل صورة مكسورة.

| الملف | الموضع | الصورة |

| `hero.jpg` | أعلى الصفحة (الهيرو) | واجهة زجاجية — **عمودية** (نسبة 4:5) |
| `01-shopfront-restaurant.jpg` | المعرض — مشروع ١ | واجهة محل مطعم بزجاج سيكوريت وباب زجاجي |
| `02-office-partitions.jpg` | المعرض — مشروع ٢ | قواطع مكاتب زجاجية بشرائح مصنفرة |
| `03-roof-terrace-glazing.jpg` | المعرض — مشروع ٣ | تزجيج جلسة سطح بأبواب سحب زجاجية |

## ملاحظات

- صور المعرض تُقصّ تلقائياً بنسبة 4:3، والهيرو بنسبة 4:5 على الشاشات الكبيرة.
- يُفضّل ضغط الصور قبل الرفع (عرض 1600 بكسل يكفي) لتسريع فتح الصفحة.
- صيغة `.jpg`. لو كانت الصيغة مختلفة، غيّر الامتداد في `index.html` أو حوّل الصورة.

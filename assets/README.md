## ملاحظات

- صور المعرض تُقصّ تلقائياً بنسبة 4:3، والهيرو بنسبة 4:5 على الشاشات الكبيرة.
- يُفضّل ضغط الصور قبل الرفع (عرض 1600 بكسل يكفي) لتسريع فتح الصفحة.
- صيغة `.jpg`. لو كانت الصيغة مختلفة، غيّر الامتداد في `index.html` أو حوّل الصورة.

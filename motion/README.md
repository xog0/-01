# موشن جرافيك: يوم ضايع (عدم الإنتاجية) · 30 ثانية · عمودي 9:16

ستة مشاهد: المنبّه 8 الصبح ← الموبايل (5 دقايق تبقى ساعتين) ← تشتت المهام ← البطارية بتخلص آخر اليوم ← "يومك راح فين؟" ← دعوة للمتابعة.
فيه طول الوقت ساعة بتجري وعدّاد "إنجاز اليوم" ثابت على 2%.

- `index.html`: الأنيميشن كله (افتحه في المتصفح تشوفه شغال مباشرة).
- `render.js`: يصوّر الأنيميشن فريم بفريم (30fps).
- `audio.py`: يولّد الموسيقى والمؤثرات الصوتية في توقيتاتها، ويضيف التعليق الصوتي لو استخدمت `--voice`.
- `voiceover.json`: نص التعليق الصوتي بالمصري وتوقيت كل جملة.

```bash
./build.sh            # موسيقى + مؤثرات -> output/motion.mp4
./build.sh --voice    # + تعليق صوتي (صوت رجل مصري، محتاج edge-tts وإنترنت)
```
